[GH #421]
Constant evaluation of virtual calls to an overrider in a derived class

During constant evaluation, a virtual function call did not find the final
overrider if the class of which it is a member is derived from the class of
the called function through an intermediate class that does not itself
override the function: The called function was not replaced.  For example,
with --c++20:

  struct A { constexpr virtual int f() const { return 1; } };
  struct NA : A {};
  struct B : NA { constexpr int f() const override { return 2; } };
  constexpr int g() { B b; const A* p = &b; return p->f(); }
  static_assert(g() == 2);  // Previously failed.

This is now fixed.
