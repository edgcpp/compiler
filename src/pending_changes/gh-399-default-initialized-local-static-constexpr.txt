[GH #399]
Default-initialized local static constexpr variables in constant evaluation

In C++23 mode, a default-initialized local "static constexpr" variable of
class type caused the constant evaluation of the enclosing function to fail.
For example, with --c++23:

  struct Q { int q = 1; };
  constexpr int f() { static constexpr Q q; return q.q; }
  static_assert(f() == 1);  // Previously failed.

This is now fixed.
