[GH #431]
Virtual function instantiation for suppressed class template specializations

Previously, in IA-64 ABI configurations with ABI_COMPATIBILITY_VERSION >= 410,
defining an inline member function of a class template specialization whose
instantiation was suppressed could unnecessarily instantiate the class's
virtual functions.  This no longer occurs when the specialization has external
linkage and its virtual function table is suppressed.  A GNU "inline template"
directive still requires the virtual functions.  For example, with
--c++11 -tused:

  template<int N> struct C {
    virtual void f() {
      static_assert(N != 1, "");  // Previously a spurious error, now okay.
    }
  };
  extern template class C<1>;
  C<1> c;
