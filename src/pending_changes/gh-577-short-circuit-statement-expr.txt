[GH #577]
C++-generating back end: Abort on GNU statement expressions in logical operands

The C++-generating back end could abort with a failed assertion in
check_for_and_take_source_seq_entry when the right operand of a
short-circuited && or || contained a GNU statement expression with a local
declaration.  For example, with --gnu_version=150200:

  struct S { bool operator&&(int); };
  bool f(int n) {
    return false && ({ int i = n; i; });  // Previously triggered an abort.
  }
