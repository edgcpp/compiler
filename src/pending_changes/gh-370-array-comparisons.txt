[GH #370]
C++26: comparison between two arrays is not allowed

A comparison between two arrays using an equality or relational operator is
deprecated in C++20 and not allowed in C++26 (P2865).  The front end did not
diagnose it.  It is now a warning in C++20 and C++23, and an error in C++26
(only a warning when emulating GCC versions before 15 or Clang versions before
20, which do the same).  For example, with --c++26:

  int a[2], b[2];
  bool x = a == b;   // Now an error.
  bool y = a == &b[0];  // Okay: one operand is a pointer.
